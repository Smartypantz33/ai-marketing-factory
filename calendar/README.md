# Calendar

This folder holds one file: `content-calendar.csv`, your team's work order. One row = one asset.

Create it in class with the calendar prompt (see the Calendar Update handout), then upload it here and delete your old calendar file.

The file must start with these columns, in this order, with these exact names:

`Asset ID, Campaign ID, Topic, Format, Channel, Station, Status, Output link, Notes, AI use, AI disclosure, Canva link, Notes for Lisa`

Your other columns can follow after these.

- **Station** is one of: social, blog-seo-geo, email, ad-creative, video-short-form, landing-page
- **Status** is one of: Not started, Drafting, In review, Revise, Done
- **Output link** always points to the asset's folder in this repo, videos included.
