# Playbook

The playbook is your factory's operating manual. Someone else (a future you, an employer, a hire) should be able to run your factory from it without asking you questions.

| Part | Covers | When you write it |
|---|---|---|
| `part-1-foundation.md` | Your agency, the context pack, onboarding a new client | Class 9 homework |
| `part-2-production.md` | How each line runs, your customizations, the review gate | Class 10–11 homework |
| `part-3-run-and-replicate.md` | Running a full cycle, reporting, pointing the factory at a new client, sharing it | Class 12 homework |
| `tool-register.md` | The tool in each station's slot, free and paid | Started Class 11, kept current |

Write in plain language. Short sections, numbered steps, real examples from your client work.
