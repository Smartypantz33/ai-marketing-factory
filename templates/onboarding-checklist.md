# Client onboarding checklist

Copy into `outputs/<client-slug>/YYYY-MM-DD-onboarding.md` and tick off as you go.

## Before kickoff
- [ ] Intake questionnaire sent and returned
- [ ] Discovery meeting booked; notes saved to `outputs/<client-slug>/`
- [ ] Scope, deliverables and timeline agreed in writing
- [ ] Approver and approval turnaround confirmed

## Access and assets
- [ ] Brand assets received (logo, colours, fonts, photos)
- [ ] Access to accounts needed (social, website, email platform, analytics), using the client's own sharing features, never their passwords
- [ ] Permissions for reviews, testimonials and customer stories confirmed in writing

## Context pack
- [ ] `brand-book.md` built or updated
- [ ] `research-personas` station run and personas approved
- [ ] `positioning-messaging` station run and positioning approved
- [ ] `voice-and-tone.md`, `offer.md` and `guardrails.md` complete
- [ ] Client has reviewed the context pack summary
- [ ] Context files loaded into the Claude Project

## First cycle
- [ ] Client brief completed (`templates/client-brief.md`)
- [ ] Content calendar approved
- [ ] Reporting dates and metrics agreed
